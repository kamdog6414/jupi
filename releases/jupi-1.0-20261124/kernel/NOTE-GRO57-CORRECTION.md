# Additive correction to jupi-update-20261124/STUDY.md (groku, Nov 24 2026). Original file not edited.
Row "Nov 23 3:35 PM | JUPI 2 boots the current kernel (boot -3), wired link up 3:35:29 PM": those times are pre-NTP. PS4s have no RTC in Linux (/sys/class/rtc absent on both, CONFIRMED); systemd restores the last saved clock at boot. At first NTP sync tailscaled logged "time jump detected (slept 2h55m47s)" (6:31:23 PM). So boot -3 really started about 6:31 PM Nov 23, the wired link was up only seconds, and "Link is down" at 6:31:26 PM was ~3 s after the clock step, right after boot (CONFIRMED from JUPI 2 journal). JUPI 1 booted at 6:34 PM the same evening.
