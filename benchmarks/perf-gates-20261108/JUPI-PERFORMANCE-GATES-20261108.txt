FINITE ARRAY / MEMORY GATES — PASSED

Workload: x <- gain*x + offset*(stage+1), eight ordered float32 stages,
gain=0.75, offset=float32(0.0001). Deterministic varied inputs. No fast-math.
Seven measured repetitions per lane, plus an untimed warmup. 1, 4,099, 65,536,
1,048,576 and 4,194,304 samples cover a tiny batch, dispatch tails and bulk data.
All CPU/GPU outputs matched the CPU reference bit for bit in all recorded lanes.

Direct-shell live-session medians at 1,048,576 samples:

  GPU first-coherent staging, fused kernel        100.576 ms
  GPU CPU-cached staging, per-stage round trips    29.963 ms
  GPU CPU-cached staging, eight resident kernels    4.349 ms
  GPU CPU-cached staging, one fused kernel          3.632 ms
  CPU serial staged reference                      5.974 ms
  CPU eight-stage specialization, four workers     1.282 ms

Changing only the fused GPU lane's staging policy reduced 100.576 to 3.632 ms
(27.69x). With cached staging fixed, eliminating intermediate host round trips
reduced 29.963 to 3.632 ms (8.25x). The best CPU lane was 4.66x faster than the
serial staged CPU reference and 2.83x faster than transfer-inclusive GPU fusion
for this simple recurrence. These ratios share one workload; they do not
multiply into a whole-system gain or compare this machine to a newer GPU.

At 4,194,304 samples the cached GPU roundtrip/resident/fused medians were
113.503 / 15.931 / 14.129 ms; the four-worker CPU specialization was 5.138 ms.
At 4,099 samples the best CPU lane was 0.00786 ms versus 0.09986 ms GPU fused.
Compute intensity, batch size, data origin and placement therefore belong in
any future routing decision. No automatic CPU substitution was added.

Vulkan reports memory type 1 as HOST_VISIBLE|HOST_COHERENT (0x6), and type 3 as
HOST_VISIBLE|HOST_COHERENT|HOST_CACHED (0xe). The latter is explicitly required
by the new default benchmark lane; absence fails rather than quietly changing
the memory policy. Device-local working storage and staging copies are explicit.
Physical shared GDDR5 does not imply OpenCL shared virtual memory: the retained
Clover driver reports unified host/device memory as NO. API heap advertisements
are not a claim that all physical memory can be allocated by a GPU job.

CPU build: GCC -O3 -march=btver2 -ffp-contract=off -fopenmp. This matches Jaguar's
instruction set; no AVX2/FMA dependency was introduced. Compiler vectorization
output is retained. Shader: glslc -O --target-env=vulkan1.0; NoContraction and
per-element stores checked in the retained SPIR-V disassembly. Vulkan 1.0
transfer/compute/host barriers and fence completion provide the synchronization.
The driver retains its own testing/nonconformance warning; qualification is for
these specific checked operations, not the entire Vulkan API.

Timing includes host copies, command recording, submissions, GPU work and
readback. Device initialization, pipeline creation, warmup and correctness
comparison are outside the timed operation. Each process still pays setup cost,
which is separately recorded. No energy, calibrated die-temperature, sustained
peak or idle-system claim is made. These are live desktop measurements.
